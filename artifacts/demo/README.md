# Материалы демонстрации

- **APK приложения**: [Release v0.1-meevo](https://github.com/Sotef/nuclear_hack/releases/tag/v0.1-meevo)
  (`Meevo.apk`, установка: `adb install -r Meevo.apk` или открытие файла на телефоне).
- **design-3-variants.html** — дизайн-макеты интерфейса (A Recorder / B Dot-Matrix /
  Aurora Glass) с пулами анимаций; реализованы в приложении как скины.
- **output/baseline/** и **output/baseline_llm/** — примеры JSON-вывода
  контракта v0.2 (13 записей тестового набора) на разных этапах проекта.
- Демо-аудио встроены в APK (`assets/audio/`): 7-минутная сказка (LibriVox,
  public domain) и короткие разговорные фрагменты.
- Видео и скриншты демонстрации — добавьте сюда при наличии.
