# ML API contract (Android integration)

Статус: черновик контракта ML-модуля. Базовый `OUTPUT CONTRACT` из `rules.md`
не меняется; ниже перечислены только согласованные точки вызова и additive-поля.

## 1. Жизненный цикл

| Метод | Назначение |
|---|---|
| `create(config)` | Создать/инициализировать ML-модуль с конфигурацией (пути к моделям, потоки, режимы). |
| `transcribe(request) -> result` | Выполнить офлайн-транскрибацию и вернуть результат. |
| `transcribeJson(request) -> json` | То же, но результат сразу в виде JSON-строки/объекта по контракту. |
| `modelInfo()` | Вернуть сведения о загруженных моделях и версиях. |
| `close()` | Освободить ресурсы (модели, потоки, память). |

## 2. Поля запроса

| Поле | Описание |
|---|---|
| `audioId` | Идентификатор аудиозаписи (строка). |
| `pcm` | PCM-аудио 16 кГц, моно (альтернатива `filePath`). |
| `filePath` | Путь к аудиофайлу (альтернатива `pcm`). |
| `durationSec` | Длительность аудио в секундах. |
| `options.llmMode` | Режим LLM-постобработки: `punctuate` \| `correct` \| `flagDoubtful`. |
| `numSpeakersHint` | Подсказка числа говорящих (необязательная). |

## 3. JSON-вывод

Базовые поля — по `OUTPUT CONTRACT` (`audio_id`, `duration_sec`, `language`,
`speakers`, `segments[]`, `meta`). Дополнительно (additive, обратно совместимо):

| Поле | Описание |
|---|---|
| `segments[].text_raw` | Текст сегмента до LLM-постобработки (сырой ASR). |
| `segments[].doubtful` | Флаги сомнительных словосочетаний для сегмента. |
| `segments[].edits[]` | Список исправлений: `{from, to, reason}`. |
| `meta.llm_model` | Идентификатор/версия использованной LLM. |
| `meta.postproc_version` | Версия модуля постобработки. |

## 4. Ошибки

| `errorCode` | Когда возникает |
|---|---|
| `E_MODEL_LOAD` | Не удалось загрузить/инициализировать модель. |
| `E_AUDIO_FORMAT` | Входное аудио не соответствует ожидаемому формату (16 кГц, моно, PCM). |
| `E_CANCELLED` | Операция отменена вызывающей стороной. |
| `E_OOM` | Недостаточно памяти для загрузки модели/инференса. |
| `E_INTERNAL` | Внутренняя ошибка модуля. |

## 5. Прогресс

Колбэк прогресса сообщает текущую стадию:

`VAD` | `ASR` | `DIAR` | `LLM` | `MERGE`

## 6. Границы

- Поля и коды ошибок выше — полный согласованный набор; новые поля/коды
  добавляются только по согласованию с оркестратором.
- `segments[].text_raw`, `segments[].doubtful`, `segments[].edits`,
  `meta.llm_model`, `meta.postproc_version` — additive; потребитель, не знающий
  о них, должен игнорировать их без ошибок.
