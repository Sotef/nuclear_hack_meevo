# Ограничения решения

## Поддерживаемые условия

- Русская речь; форматы аудио wav/mp3/ogg/flac/m4a (стерео и любая частота
  дискретизации приводятся к моно 16 кГц).
- 1–4 говорящих в записи (диаризация автоматическая, число не задаётся).
- Записи от секунд до десятков минут; на очень длинных (>1 ч) растёт память
  LLM-этапа (диалог целиком).
- Устройства arm64-v8a, Android 8+; ОЗУ от 4 ГБ (рекомендуется 6 ГБ).

## Известные ограничения

- **Качество ASR** замерено на аудиокнигах (RuLS) и синтетике; на спонтанной
  речи, телефонии и шуме WER не измерен (нет размеченных данных).
- **DER 0.48** — на синтетическом наборе, завышен miss-ом из-за разметки;
  реальных разговоров с RTTM-разметкой в наборе нет.
- Перебивания (overlap) не восстанавливаются: модель ASR отдаёт один поток текста.
- Модель ASR обрабатывает чанками по 60 с — на стыках редко теряются фрагменты.
- Пунктуация (RUPunct) не ставит кавычки и не исправляет слова ASR; режим правок
  слов LLM деградирует по WER и выключен.
- LLM (1.7B) местами тавтологичен в конспекте и может «улучшать» текст при
  длинных репликах — на смысловые задачи влияет слабо, но конспект стоит читать
  критически.
- Склейка разрезанных фраз выполняется только для соседних сегментов.
- Интерфейс на английском/русском без локализации; планшетный режим не оптимизирован.

## Что не входит в текущую версию

- Streaming-распознавание в реальном времени (пайплайн пакетный).
- Ручная правка сегментов и спикеров в UI.
- История расшифровок с переоткрытием; облачная синхронизация (вне скоупа по ТЗ).
- Языки кроме русского; перевод; именование спикеров («Иван» вместо SPEAKER_1).
- Экспорт DOCX/PDF; публикация субтитров на видео.
- VAD-детекция речи (тишина и так корректно обрабатывается ASR).

## Риски демонстрации

- Первый запуск распаковывает модели (~1.5 ГБ, до минуты) — заложить время.
- LLM-анализ добавляет ~2.5 мин на 7-минутную запись — для демо можно оценить
  скорость на коротком фрагменте (20 с ≈ 1.5 мин с LLM).
- На устройствах с 2–3 ГБ ОЗУ LLM-этап может быть вытеснен системой.
- Samsung-устройства «замораживают» приложение при выключенном экране
  (Freecess) — для длинных прогонов держать экран включённым.

## Дальнейшее развитие

- MiniCPM5-2B с T-Wix-адаптером (punct F1 0.782) после починки токенизатора
  в ONNX Runtime GenAI — повысит качество LLM-этапа.
- VAD → сегментация до ASR; восстановление перебиваний (overlap-aware merge).
- Streaming-режим и фоновая обработка (WorkManager).
- Ручная правка в UI, именование спикеров, история.
- Оптимизация памяти LLM (KV-кэш, выгрузка, квантизация int4 LiteRT).
