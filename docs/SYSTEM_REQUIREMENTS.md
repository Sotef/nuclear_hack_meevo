# Рекомендуемые системные требования

## Устройство (приложение Meevo)

| Параметр | Минимум | Рекомендуется | Обоснование |
|---|---|---|---|
| Архитектура | arm64-v8a | arm64-v8a | APK собирается только под arm64 |
| Android | 8.0 (API 26) | 10+ | minSdk 26; на 8–9 не тестировалось |
| ОЗУ | 4 ГБ | **6 ГБ** | пик приложения: ~1.9 ГБ (LLM 1.5 ГБ + стадии + ОС) |
| Свободное место | 4 ГБ | 6 ГБ | APK 1.4 ГБ + распаковка моделей ~1.5 ГБ + экспорт |
| Процессор | 4 ядра | 8 ядер (big.LITTLE) | полный прогон 7 мин аудио ≈ 4.5 мин без LLM и ≈ 7 мин с LLM |
| Экран | — | 5"+ | список реплик + плеер |

Практическая проверка: Samsung SM-N9750 (Snapdragon 855, 8 ГБ, Android 12) —
RTF 0.44 без LLM и ~1.06 с LLM-анализом на 7-минутной записи, перегрева нет
(батарея 21–22 °C после серии прогонов). Устройства с 2–3 ГБ ОЗУ будут упираться
в пик LLM (работает, но с риском вытеснения других приложений).

Оценки времени обработки (см. docs/RESEARCH.md, замеры на SM-N9750):

| Длительность записи | Без LLM | С LLM-анализом |
|---|---|---|
| 1 мин | ~25 с | ~1.5 мин |
| 7 мин | ~3 мин | ~7 мин |
| 20 мин | ~9 мин | ~18 мин |
