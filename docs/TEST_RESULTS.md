# Методика и результаты тестирования

## Методика

- **Набор**: `artifacts/data/test` — 13 записей (497 слов, 5.2 мин):
  10 фрагментов аудиокниг RuLS (CC-BY-4.0, OpenSLR SLR96), 3 синтетические
  многоговорящие записи с RTTM-разметкой (MIT). Манифест — `manifest.jsonl`.
- **Инструменты** (детерминированные, версии в выводе): `src/tools/eval_asr`
  (WER, нормализация: нижний регистр, ё→е, удаление пунктуации),
  `src/tools/eval_diar` (DER, collar 0.25), `src/tools/eval_postproc`
  (punct P/R/F1, boundary F1, ΔWER, false-alarm).
- **Устройство**: Samsung SM-N9750 (Snapdragon 855, 8 ГБ, Android 12) —
  все RTF/RAM сняты на реальном телефоне (не эмуляторе).
- Сравнение кандидатов — всегда на одном наборе одним инструментом; повторные
  прогоны идентичны (greedy-декодинг, SHA-256 гипотез совпадает).

## Результаты

| Punct F1 / boundary F1 (QVikhr LLM) | 0.757 / 0.849 | для сравнения |

### Корректность и надёжность

- JSON-контракт v0.2: 13/13 валидны (`merge.py --validate-only`), детерминизм
  повторных прогонов подтверждён (SHA-256 совпадает).
- Экспорт: JSON + SRT + TXT + схема за один проход, форматы сверены с контрактом.
- Многоформатный вход: wav/mp3/ogg/flac/m4a проверены на устройстве.

Полные отчёты экспериментов: `artifacts/test-results/reports/`
