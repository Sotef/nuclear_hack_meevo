# Функции приложения Meevo

## Основной сценарий

Одна кнопка **«Обработать всё»** запускает полный конвейер. Результат —
расшифровка с таймкодами и говорящими, конспект и главы. Лишних кнопок нет.

## Источники аудио

- **Микрофон** — запись с индикатором (пульсирующие кольца, таймер, мигающая
  точка), автоматически становится источником после остановки.
- **Файл** — выбор любого аудио: wav, mp3, ogg, flac, m4a (декод через MediaCodec).
- Демо-записи вшиты в приложение (7-минутная сказка, короткие разговоры).

## Обработка (пять стадий, реальный прогресс)

1. **Декод** — аудио → моно 16 кГц;
2. **ASR** — GigaAM v3: текст + тайминги, прогресс по чанкам (60 с);
3. **Диаризация** — кто говорил когда, ID стабильны на всю запись;
4. **Пунктуация** — т9-модель RUPunct: знаки и регистр (мгновенно);
5. **LLM-анализ** — склейка случайно разрезанных фраз (в т.ч. между спикерами),
   главы с таймкодами, конспект.

На экране обработки: суммарный прогрессбар, строка на каждую стадию
(○ → ● → ✓, процент, ETA этой стадии) и общий таймер **«Осталось ~M:SS · этап N/5»**
с пересчётом по фактической скорости. Этапы отмечаются галочками по мере готовности.

## Результат

- **Табы**: Текст (реплики «SPEAKER · MM:SS + текст», тап — перемотка),
  Сводка (конспект тезисами), Главы (таймкоды, тап — переход к блоку).
- **Плеер**: воспроизведение/пауза, ползунок, тап по реплике или главе —
  перемотка аудио на нужный таймкод.
- Сомнительные сегменты (после склейки кросс-спикерных обрывов) помечаются ⚠.

## Экспорт (одна кнопка)

Сохраняет все форматы разом в приватный каталог приложения:
- `*.json` — контракт v0.2 (текст, text_raw, правки, summary, chapters, meta);
- `*.srt` — субтитры с таймкодами и говорящими;
- `*.txt` — текст диалогом «MM:SS SPEAKER: фраза»;
- `*.schema.json` — альтернативная схема `{transcript:[{speaker_id,start_ms,end_ms,text}]}`.

## Оформление

Три скина по дизайн-макетам (`artifacts/demo/design-3-variants.html`):
- **A · Recorder** — Material 3, фиолетовый, Roboto;
- **B · Dot-Matrix** — моноширинный JetBrains Mono, красный акцент, «принтерный» стиль;
- **C · Aurora Glass** — тёмная тема с градиентами (Manrope/Playfair).

Анимации: ripple на кнопке, пульс записи (3 кольца), мигающий индикатор записи,
эквалайзер, кнопка-успех с галочкой, появление результата.

## Прочее

- Полный офлайн: приложение не запрашивает `INTERNET`.
- Состояние переживает поворот экрана (модели и результат не теряются).
- Системный промпт LLM хранится в `files/config/system_prompt.txt`,
  редактируется вручную (файловый менеджер / adb) и применяется без пересборки.
